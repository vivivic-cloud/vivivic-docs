# 폰에서 이 볼트 쓰는 법

이 저장소(`vivivic-cloud/vivivic-docs`)를 옵시디언 볼트로 씁니다. 노트는 `옵시디언/` 폴더에 쌓입니다.
새 노트는 Claude가 이 폴더에 올립니다. 폰에서는 **받기(pull)** 만 하면 됩니다.

## 방법 1 — 옵시디언에서 받기 (Obsidian Git 플러그인)

1. 옵시디언 앱에서 **새 볼트**를 만듭니다. 이름은 `vivivic`, 위치는 폰 내부 저장소로 합니다. 동기화(iCloud/Sync)는 끕니다.
2. 설정 → 커뮤니티 플러그인 → 제한 모드 끄기 → **Obsidian Git** 설치 후 켭니다.
3. GitHub에서 토큰을 만듭니다. 설정 → Developer settings → Fine-grained tokens → 저장소 `vivivic-docs` 하나만 선택하고 **Contents: Read-only** (폰에서 노트를 쓰고 올릴 거면 Read and write)로 만듭니다.
4. Obsidian Git 설정에서 사용자 이름은 GitHub 아이디로, 비밀번호/토큰은 3번 토큰으로 입력합니다.
5. 명령 팔레트(상단 ⋯ 또는 아래로 당기기) → **Obsidian Git: Clone an existing remote repo** →
   `https://github.com/vivivic-cloud/vivivic-docs` 입력, 폴더는 비워 둡니다.
6. 이후 새 노트가 올라오면 명령 팔레트에서 **Obsidian Git: Pull** 을 실행합니다.

> [!warning] 폰 앱은 실험 기능입니다
> 이 저장소에는 앱 코드와 스크린샷도 있어서 폰에서 받다가 멈추거나 앱이 꺼질 수 있습니다.
> 실패하면 방법 2를 쓰세요.

## 방법 2 — 깃허브 화면으로 바로 보기 (설치 없음)

폰 브라우저에서 아래 주소를 엽니다. 표와 흐름도(Mermaid)가 그대로 그려집니다.

https://github.com/vivivic-cloud/vivivic-docs/blob/main/옵시디언/영림원/00%20홈.md

## 참고

- 이 저장소는 **공개**입니다. 금액·비밀번호·사업자번호 같은 실제 거래 자료는 이곳 노트에 넣지 않습니다.
- `.obsidian/.gitignore` 가 옵시디언 설정 파일이 깃에 올라가 충돌하는 것을 막습니다.
