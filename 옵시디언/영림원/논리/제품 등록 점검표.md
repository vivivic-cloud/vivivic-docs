# 제품 등록 점검표


상품 하나를 고르면 **품목 · BOM · 엣지필름 · 공정흐름 · 흐름 안 공정 · 소요자재 · 워크센터 · 외주계약** 상태를 O / ✕ / 대기 / 오류로 한눈에 보여 준다. ✕를 누르면 해당 단계로 이동해 같은 상품을 고른 채 이어진다. **저장소에 아무것도 쓰지 않는다.**

- 가상 화면(단계 줄 맨 위 단추). 판정 근거는 [[미등록 안내]]와 같은 폼 기록.
- 공통부속은 줄마다 겹쳐 나온다.
