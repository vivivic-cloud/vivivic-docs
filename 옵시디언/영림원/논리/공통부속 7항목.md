# 공통부속 7항목


> [!tip] 판정 기준
> **원장명 · 마감 · 마감색상 · 재단W · 재단D · W엣지면 · D엣지면** 이 모두 같으면 같은 부속. 부속명·제품·시리즈는 보지 않는다.

- 같은 부속은 품목 **하나**로 만들어 여러 제품 BOM이 나눠 쓴다.
- 원장 1,397줄: 서로 다른 부속 **680** = 공통 **290** + 단독 **390**. (재단W·D가 빈 칸이라 억지로 묶인 공통부속 6개.)
- 영림원 품목등록에는 '공통부속' 표시 칸이 없다. 같은 품번이 여러 BOM에 들어가는 것으로만 드러난다.
- **미결:** 단서를 어느 칸·어떤 꼴로 둘지([[미결 사항]]).
- 분석 도구는 저장소 `공통부속분석/`. CSV는 공개 저장소라 올리지 않고 `분석.py`로 재생성.
