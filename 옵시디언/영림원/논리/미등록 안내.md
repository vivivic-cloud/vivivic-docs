# 미등록 안내


상품검색으로 상품을 골랐는데 앞 단계가 안 돼 있으면 **막지만 말고** 무엇을 어느 단계에서 등록할지 절차를 보여 주고, '등록하기'를 누르면 그 단계로 가서 값을 미리 채워 준다(저장은 사람). 돌아오면 같은 상품을 다시 골라 이어진다.

- 판정은 폼 기록 기준: 완료=영림원에 있음 / 대기·진행중·수정대기=등록 중 / 오류뿐·없음=미등록.
- 채우는 값 예: 제품 품명=`T`+원장 단품명, 부속 품명=`T+시리즈+부속명+W x D+마감색상`, 규격 `W*D`, 소분류는 후보가 **하나일 때만**. 품번·기준단위는 비워 둔다.
