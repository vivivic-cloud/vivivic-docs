# BOM 소요량 계산


원장 1장에서 나오는 부속 개수 n (에이엠티 재단 편집기와 **같은 공용 모듈** `shared/원장재단수량.js`):

```
n = ⌊(원장W − 5 + 4.5) ÷ (부속W + 4.5)⌋ × ⌊(원장D − 5 + 4.5) ÷ (부속D + 4.5)⌋
    전단컷 5mm · 톱날 4.5mm · 바둑판 한 방향 · 자투리 몫은 안 셈
```

→ 부속 BOM의 소요량 = **1 / n**.

- **결방향 있음** 체크: 켬 = 부속을 돌리지 않음 / 끔 = 더 많이 앉는 쪽으로 돌림. 기본값은 원장 엑셀 결보호 칸(`X`·모름=끔, `O`·섞임=켬).
- 예) 784×396 on 2440×1220 → 3×3 = 9 → **1/9**. 백판넬 1172×758은 돌리면 **1/3**, 결 그대로면 1/2.
- 자재 규격에 원장 크기가 없거나 모품목 규격이 없으면 계산하지 않고 노란 이유 줄. 사람이 고친 값은 덮지 않는다.
- `grain`(결방향)은 저장 문서에만 있고 **영림원엔 안 보낸다**.
- 하위가 원장 자재일 때만 계산. 엣지필름 자재는 1/n 계산 안 함([[엣지필름 소요량]]).
