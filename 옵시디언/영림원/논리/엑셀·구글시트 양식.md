# 엑셀·구글시트 양식


- 단추는 **양식 다운로드 / 일괄 업로드** 둘, 누르면 로고로 엑셀·구글 선택.
- 열 이름은 영림원 화면 글자 그대로, 필수는 `*`, 열마다 설명 메모, 숨긴 '목록' 시트+드롭다운. 올리기는 모든 길이 `takeSheet` 한 함수.
- 여러 줄 올리면 업체마다 버튼이 있는 **일괄 업로드 목록**(준비중/필수 빠짐/이름 겹침/…). '모두 저장'은 준비중만 파일 순서대로. **덮어쓰지 않는다.**
- 구글시트 양식은 **고정 파일**이라 목록이 저절로 늘지 않는다. **사장님은 엑셀 저장이 안 되어** 구글시트가 필수 → 새 단계를 만들면 구글시트 양식도 같이.
- [[07 BOM]] 양식은 영림원 500302 실제 양식(1행 영어 코드·2행 한글·3행 자료, 37열)과 같게 맞췄다.
