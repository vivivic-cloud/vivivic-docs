# 상품검색 공용 부품


조혼가구 '제품 발주 상품검색'을 **베끼지 않고 연결**했다.

- 논리: `shared/발주상품검색.js`, 화면: `shared/발주상품고르기.html`(iframe). 한 곳을 고치면 조혼가구와 이 폼이 같이 바뀐다.
- 검색 방법 셋: **상품검색 · ING단품명 · 카테고리**(대→중→소→색상, 선택지가 하나면 자동 통과).
- 제품을 고르면 원장에서 부속 줄을 가져와 [[공통부속 7항목]]으로 묶고, 같은 부속이 여러 번이면 세트별소모량을 합산(상판1+지판1=2).
- 쓰는 곳: [[04 품목]] 품명 · [[07 BOM]] 모품목 · [[08 품목별 공정흐름]]·[[09 제품별공정별소요자재]]·[[10 제품별공정별워크센터]] 줄 펴기 · [[제품 등록 점검표]].
- 원장은 파이어스토어 `excel_metadata` 최신 문서의 엑셀(1,397줄·58열)을 **읽기만**.
- 새 단계에 붙일 때는 `fn.opening` 막음을 단다(틀이 다시 뜰 때 오는 '풀림' 알림이 표를 지움).
