# 원장 부속코드 to 공정흐름


```
부속의 공정 = 재단 → 엣지 → 보링 → NC 중 '부속코드'가 있는 것만 순서대로
흐름 이름   = 위 공정을 '-'로 이음      예) T재단-T엣지-T보링
제품 줄     = 조립부속코드가 있으면 T조립
```

원장 58열 중 단서: `재단부속코드 · 엣지부속코드 · 보링부속코드 · NC부속코드 · 조립부속코드`. 값이 있으면 그 공정을 거친다.

- [[06 공정·공정흐름]]에 그 이름이 있으면 [[08 품목별 공정흐름]] 드롭다운 **처음 값**, 없으면 비우고 '등록되지 않은 조합' + 6단계로 안내.
- 같은 부속인데 원장 줄마다 코드가 달라 조합이 갈리면 **비우고 이유를 적는다**(짐작 금지).
- 화면엔 코드가 아니라 '원장 공정: 재단 엣지 보링'처럼 이름만 보인다(확인용, 문서·영림원엔 안 감).
- 알렉스 14부속 결과: p01·p02 재단-엣지 / p03~p10 재단-엣지-보링 / p11~p14 재단.
- 원장 전체: 재단 203 · 재단엣지 393 · 재단엣지보링 752 · 재단보링 9 · 재단엣지보링NC 12 · 코드 없음 28줄.
- ⚠ **곡면엣지·멤브레인 코드 열은 원장에 없다** → 자동으로 안 나옴, 사람이 고른다.
- 자동 값은 어디까지나 처음 값. 사람이 고르면 덮지 않는다.
