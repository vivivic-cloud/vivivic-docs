# 이름 규칙


- 테스트 자료는 이름 앞에 `T` (T에이엠티, T조혼가구, T재단 …). 기존 영림원 자료는 건드리지 않는다.
- 제품 품명 = `T` + 원장 단품명 **글자 그대로**. 예) `T(KRW) 알렉스 800 높은 수납장 올화이트`. "(KRW)"를 떼면 다른 프로그램에서 검색이 안 된다.
- 흐름 이름 = 공정명을 `-`로 이음(`T재단-T엣지-T보링`). **공정 이름에는 `-` 금지.**
- T워크센터의 창고 6종은 **그 워크센터와 같은 이름**. 업체 간 이동은 자재이동으로.
- 칸 키에 `status · agentNote · createdAt · route · rows`는 쓰지 않는다([[상태 흐름]]).
