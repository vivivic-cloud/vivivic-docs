# 미결 사항

## 사장님 결정이 필요한 것
- [ ] **중간 공정의 '공정품'** — 공정 2개 이상 품목의 중간 공정은 사외외주면 공정품이 필수라 저장이 막힌다. 일괄등록은 공정품을 최종 공정 줄에만 넣음. → [[10 제품별공정별워크센터]]가 여기서 멈춤
- [ ] **공정별 재고(재공품)** — 공정품일괄생성(523268)·재공재고조회(501186)를 찾았으나 500228의 숨은 칸 '공정품일괄생성대상'이 모두 꺼져 대상 0줄, 켜는 길 미확인
- [ ] **공통부속 단서**를 어느 칸·어떤 꼴로 둘지 → [[공통부속 7항목]]
- [ ] 원장↔품목 **영구 연결 열쇠** 저장 여부(지금은 이름+규격 임시 규칙). 제품은 ing단품명, 부속은 7항목 키를 [[04 품목]] 문서에 저장하면 위 항목과 한 번에 해결(제안만)
- [ ] **[[11 외주계약]] 구조** — '제품×공정 단가와 공정별 담당 업체표만 입력하고 에이전트가 단가×업체로 행을 펴서 넣는' 구조 제안, 미확정. 현재는 업체마다 단가 반복
- [ ] 완료된 엣지 BOM 10건은 v62 이전 옛 식 값 → [[엣지필름 소요량]]
- [ ] 영림원에 직접 넣은 자료(T우정 등)와 옛 규칙 분류 `T수납장(2003015)` · `T원자재>T판재>T화이트` 처리
